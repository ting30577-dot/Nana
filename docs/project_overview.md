# AlgoMind · 项目全景文档

> **性质**：面向 AI/CS 方向学习者的桌面学习工作台  
> **定位**：不是入门教程，是认真学习者的研究环境  
> **开源**：MIT License，GitHub 公开

## 一、产品定位

### 目标用户

已掌握基础数据结构，正在系统深入算法并开始接触科研论文的 AI/CS 方向学生。

### 核心模块

```text
左侧图标导航栏（VS Code 式）
│
├── 算法工作台   按模式组织，不是教材式算法名称列表
│                每个模式：场景分析 · 可视化 · 复杂度 · 关联题
├── 论文库       三栏布局：列表 / PDF 阅读 / 结构化笔记
│                标注 · 标签 · 阅读进度
├── 刷题追踪     LeetCode 记录 · 按模式统计 · 复盘
├── 知识图谱     算法模式 ↔ 论文知识点连接（后期）
└── 设置         主题 · 数据目录 · 快捷键
```

### 算法模块的分类逻辑

| 传统（教材式） | AlgoMind（模式式） |
| --- | --- |
| 排序算法 > 冒泡、快排 | 双指针 > 对撞、快慢、滑动窗口 |
| 搜索算法 > BFS、DFS | 单调结构 > 单调栈、单调队列 |
| 图算法 > Dijkstra | 二分 > 值域二分、二分答案 |

## 四、v0.1 模块详细设计

### 4.1 窗口框架

- 主窗口尺寸：1280 × 800，可拖拽调整
- 左侧导航栏：60px 宽，深色背景，图标按钮垂直排列
- 右侧内容区：根据选中模块动态切换

### 4.2 算法工作台（v0.1 范围：滑动窗口）

左侧模式列表（240px）：

- 模式分类树：当前只有“滑动窗口”（后续版本扩充）
- 子分类：固定窗口 / 可变窗口

右侧主面板：

- 顶部信息卡：适用场景、时间复杂度、空间复杂度、核心约束
- 中间分屏：左侧代码（Python，语法高亮）/ 右侧动画区
- 动画控件：速度滑块、开始、暂停、重置、单步
- 底部：关联 LeetCode 题目标签

v0.1 实现的可视化：

1. 固定窗口：维护固定大小 `k` 的窗口在数组上滑动，高亮当前窗口。
2. 可变窗口：双指针 `l/r` 扩张与收缩，条件满足时更新答案。

### 4.3 v0.1 不做的内容

- 论文库（v0.3）
- 刷题记录（v0.2）
- 数据持久化（v0.2 引入 SQLite）
- 多个算法模式（v0.2 扩充）
- 设置页面（仅占位图标）

## 五、开发原则

1. MVP 优先：每个版本只做够用的功能。
2. 第一行代码就上 GitHub：没有“做完再开源”。
3. AI 写代码，自己懂架构：能读懂、能改、能描述 bug。
4. README 先于代码：每个版本开始前写清楚要做什么。
5. 每个功能完成就 commit：保持 GitHub 活跃。
