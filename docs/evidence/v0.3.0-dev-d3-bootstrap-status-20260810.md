# D3 bootstrap projection-status evidence — 2026-08-10

The read model and shared browser projection now derive a bootstrap `degraded` status when
the bounded Activity suffix contains an aggregate/type pair not covered by the
bootstrap canonical collections or an implemented reducer patch. A known
aggregate with a future or mismatched Event type is therefore still degraded.
Covered
Workspace/research facts remain `ready`; Activity-only `budget`, `relation`,
Approval and other future aggregates require an upgrade banner instead of
being silently presented as fully understood.

The server scans all committed Event aggregate/type pairs inside the same read
transaction, so an unknown or mismatched Event older than the bounded Activity suffix still
sets the status. This matches the existing SSE and D2 replay behavior: unknown Events remain
Activity and consume their cursor/watermarks, but never invent domain state.
Vitest covers covered and unknown bootstrap aggregate cases. No runtime route,
mutation, authorization, capability, or filesystem behavior changed.
