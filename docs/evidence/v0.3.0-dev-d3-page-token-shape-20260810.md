# D3 signed page-token shape evidence — 2026-08-10

The read-model page-token decoder now rejects JSON booleans supplied as
`high_water` or `offset`. Python treats `bool` as an `int` at runtime; the
decoder uses an exact integer-type check so malformed signed token payloads
fail with `E_PAGE_TOKEN` rather than entering SQL pagination.

The D3 read-model suite covers both boolean positions and remains green under
the ResourceWarning-as-error subset. This is a read-only token validation
repair; it does not change the high-water contract, route inventory, or any
D3-07 implementation flag.
