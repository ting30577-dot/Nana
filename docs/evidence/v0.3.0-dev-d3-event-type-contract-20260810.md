# v0.3.0-dev D3 canonical Event type contract evidence — 2026-08-10

The read-only projection now recognizes canonical events by the pair
`aggregate_type` + `type`, not by aggregate type alone. A future or mismatched
event type remains visible in Activity, marks the projection `degraded`, and
cannot patch Run, Action, Artifact, Hypothesis, or Finding state. The Python
bootstrap read model applies the same pair whitelist across all committed
outbox-published events, including events older than the bounded Activity
suffix.
