# v0.3.0-dev D3 projection-status contract evidence — 2026-08-10

This continuation closes a small frontend contract ambiguity without widening
the D3-07 gate. `ProjectionStatus` now contains only canonical bootstrap /
reducer states: `ready` and `degraded`. Transport or reducer failure remains
the store's terminal `projection_unavailable` phase and is never represented
as a partially usable projection.

The bootstrap parser rejects both arbitrary values and the former `error`
value with `E_BOOTSTRAP_STATUS`; unknown canonical events still preserve the
event as activity and downgrade the projection to `degraded`.

- `npm.cmd run test`: 25 Vitest tests passed plus projection self-test.
- `npm.cmd run check`: TypeScript strict check passed.
- No D3-07 machine gate flags changed; Approval/T3/export/filesystem-write
  behavior remains unimplemented and unauthorized.
