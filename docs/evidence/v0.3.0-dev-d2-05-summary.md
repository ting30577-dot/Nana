# v0.3.0-dev D2-05 证据摘要

D2-05 本次实现 runtime budget accounting：

- schema 升级到 v5，新增 `run_budget_ledger`。
- 新增 `nana_sidecar/storage/budget_accounting.py`。
- `RunSchedulerService.claim_action(...)` 在启动 Action 前做 budget reservation。
- `LockedUnittestExecutorService` 在 receipt completion transaction 内记录 actual usage。
- ledger 从 Run frozen snapshot 读取 budget limit，不信任 Action 自报 budget。
- ledger 懒初始化时会从已有 Action/Receipt 重建 started/running/usage，避免迁移后低估。
- `max_actions` 达到上限会阻止新 Action，并产生 `budget.threshold_reached` 与 `run.budget_exceeded`。
- `max_concurrency` 达到上限会阻止本次 claim，但不把 Run 误终止。
- `wall_clock_ms`、`output_bytes`、`artifact_bytes`、`model_tokens`、`cost_micros` 等 actual usage 由 receipt/fail-closed estimator 接入累计。
- failed / timed_out / effect_unknown Action 的 usage 也会入账。
