# D3 canonical Event timestamp fingerprint evidence — 2026-08-10

The shared browser reducer now normalizes an explicit ISO-8601 Event
`occurred_at` timestamp to UTC before computing its canonical fingerprint.
Timezone-naive or malformed strings are retained unchanged so the reducer
never silently repairs invalid canonical data.

Vitest proves that `2026-08-08T08:00:00+08:00` and
`2026-08-08T00:00:00Z` have the same fingerprint and that applying the second
Event with the same ID is an exact duplicate (no cursor or state advance).
TypeScript strict check and the full frontend unit/self-test pass after the
change. This remains read-only projection behavior and does not alter any
D3-07 gate flag or write capability.
