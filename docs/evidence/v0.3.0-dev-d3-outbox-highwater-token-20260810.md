# D3 committed-outbox projection and page-token evidence — 2026-08-10

Bootstrap high-water, Activity, section pages, aggregate watermarks, and run
sequence watermarks now share the same committed-fact boundary: each query joins `events` to
`outbox_events`. An Event row that exists before outbox publication is not
projected even when a later published Event advances the high-water cursor.

Signed section tokens now encode the payload and HMAC signature as separate
base64url components. This removes the previous binary-delimiter ambiguity,
where a `.` byte inside the HMAC could make a valid token fail closed
intermittently. Existing section binding, offset bounds, signature checks and
high-water anchoring remain unchanged.

Read-model regression tests cover unpublished rows below a later high-water,
Activity pages, aggregate watermarks, and repeated token decoding. No runtime
mutation, authorization, capability, or filesystem behavior changed.
