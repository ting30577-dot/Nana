# D3 Action projection privacy evidence — 2026-08-10

The canonical bootstrap Action whitelist now excludes `policy_decision`,
`authorization_ref`, `capability_version`, and `risk_tier`. The browser
receives only Action identity/relations, capability identity, state and
timestamps, while literal
`waiting_approval` continues to populate `needs_you`. Authorization source,
grant references and decision material are not returned or re-derived.

A read-model regression seeds a waiting Action containing a deliberately
private authorization reference and proves that neither field or value appears
in the snapshot. No admission, authorization, mutation, capability, or
filesystem behavior changed.
