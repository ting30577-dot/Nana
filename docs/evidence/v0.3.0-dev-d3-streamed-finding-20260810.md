# D3 streamed Finding projection evidence — 2026-08-10

The shared reducer now treats canonical `finding` Events as a supported
projection aggregate. A `finding.drafted` Event updates the Finding map with
its statement, status, evidence IDs, and producer Run, while preserving the
canonical projection status as `ready`; it is not downgraded to unknown-event
activity.

Coverage includes a TypeScript unit test and a real-browser Playwright test
that streams a Finding after bootstrap and verifies the statement, producer
Run, Evidence ID, cursor advance, and absence of the degraded banner. This is
read-only projection behavior and does not add a command, route, authorization
query, capability, or filesystem write.
