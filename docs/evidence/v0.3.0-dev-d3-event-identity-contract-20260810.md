# D3 Event identity contract evidence — 2026-08-10

The browser projection, bootstrap Activity validator, and SSE parser now share
the canonical Event relationship rules: `run_id` and `action_id` are either
non-empty identifiers or null, and a positive `run_seq` requires a non-null
`run_id`. Empty relationship strings and orphaned run sequences fail closed
before fingerprinting or cursor advance.

Vitest covers replay/reducer, bootstrap, and SSE malformed-envelope cases. The
server-side contract remains authoritative; this is a client-consumption
boundary and does not add identifier format inference or authorization logic.
No route, mutation, capability, filesystem, or runtime write behavior changed.
