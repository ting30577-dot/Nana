# D3 shared Event envelope validation evidence — 2026-08-10

The pure projection reducer now validates the canonical Event envelope before
fingerprinting or advancing the cursor. It rejects non-safe/zero IDs, empty
aggregate or type fields, invalid aggregate/run sequence values, and non-object
payloads with `E_EVENT_ENVELOPE`. This validation is shared by browser SSE and
offline replay because both paths call the reducer; the SSE parser continues to
apply its stricter transport checks.

D2 handoff replay Events may omit the transport/domain timestamp field present
on live SSE frames; the reducer treats that single field as an explicit replay
omission and canonical JSON omits the undefined member rather than inventing a
timestamp. All other envelope fields remain required and fail closed.

The malformed-envelope matrix passes in Vitest, the D2 projection self-test
still passes, and the complete read-only browser suite remains green. No
runtime route, command, authorization, capability, or write behavior changed.
