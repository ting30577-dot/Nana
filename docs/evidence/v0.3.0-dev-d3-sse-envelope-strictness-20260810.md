# D3 SSE envelope strictness evidence — 2026-08-10

The browser SSE adapter now rejects empty `aggregate_type`, empty
`aggregate_id`, and empty `occurred_at` values at the transport boundary. This
keeps the SSE parser aligned with the shared projection Event envelope instead
of allowing malformed identity/timestamp fields to reach the reducer.
