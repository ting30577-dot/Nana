# D3-08B Codex-only implementation exit

Date: 2026-08-13  
Decision: **ACCEPT**

D3-08B safely exposes the already-proven D3-07 one-time Approval and exact
`export.draft_external` capability. The launcher/CLI remains the only genuine
user target chooser. React receives only an opaque LocalSession selection ID,
redacted label, expiry and provenance; the explicit Playwright harness is
labelled `test_harness` and is not represented as interactive user evidence.

The Approval control binds its decision to the canonical Approval ID,
revision and subject hash. The browser cannot select capability, path,
filename, bytes, authorization, risk or effects. After approval, the runtime
executes on the owner lane and the UI waits for canonical Action/Receipt facts.
No command response is treated as write success.

## Browser matrix

Four isolated temporary Workspaces, each with a new selection and chain:

1. approved once -> fixed local draft -> succeeded Receipt;
2. denied -> no authorization and cancelled Export Run;
3. expired -> canonical expiry and no authorization;
4. crash after durable first-write fence -> orphaned/effect_unknown Receipt,
   quarantined with no retry/resume/rebind/dismiss control.

Each Playwright invocation uses one Chrome worker and `retries=0`. The success
case reloads and re-proves the canonical Receipt and runs Axe on the fully
populated interface.
