### 6.3 结论边界

- D0 证明 schema、状态机、关系、命令、事件、定位器和授权输入可以从同一 Python
  契约生成 OpenAPI/TypeScript 类型；
- D0→D1 模拟证明 Artifact metadata、Event 与 outbox 的 schema 形状可原子提交、
  崩溃前回滚、重开并按 cursor 精确补齐；三个 Artifact 生命周期 payload 在
  Python、SQLite 与生成 TypeScript 三层一致；
- D0 证明 vNext schema 与 legacy tables 隔离、WAL 开启、迁移失败整步回滚、
  较高 schema 与篡改 migration hash 被拒绝，非空未版本化数据库不会被追加
  vNext tables；
- D0 证明 Action 内容变化会使一次性 Approval 失效，PolicyGrant 只匹配完整约束，
